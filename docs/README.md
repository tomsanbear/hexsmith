# Hexsmith Docs

This directory tracks research, decisions, notes, and architecture sketches for `hexsmith`.

## Structure

- [`research/`](research/) — web research reports and source notes.
- [`decisions/`](decisions/) — lightweight ADR-style decisions.
- [`architecture/`](architecture/) — evolving architecture notes and design sketches.
- [`notes/`](notes/) — working notes, meeting notes, and unresolved questions.

## Current focus

`hexsmith` is a deterministic Rust game-engine harness for sequential Civilization VI-style simulation. The core goal is reproducible, cross-platform replay from initial state plus action log.
